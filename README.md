<h2 style="text-align:center; color:#38bdf8;">DSA Roadmap (FAANG Level)</h2>

<ul>

<li><b>1. Arrays</b>
  <ul>
    <li><b>Operations:</b> Traversal, Insert (at index), Delete (shift logic), Reverse (iterative + recursive), Rotate (left/right), Prefix sum</li>
    <li><b>Algorithms:</b> Kadane’s Algorithm, Dutch National Flag, Sliding Window, Two Pointer</li>
    <li><b>Patterns:</b> Sliding Window, Two Pointers, Prefix Sum</li>
  </ul>
</li>

<li><b>2. Strings</b>
  <ul>
    <li><b>Operations:</b> Reverse, Palindrome check, Frequency count, Substring generation</li>
    <li><b>Algorithms:</b> KMP, Rabin-Karp, Z Algorithm (optional)</li>
    <li><b>Patterns:</b> Two pointers, Sliding window, Hashing</li>
  </ul>
</li>

<li><b>3. Hashing</b>
  <ul>
    <li><b>Operations:</b> Put, Get, Remove, Frequency map, Collision (basic idea)</li>
    <li><b>Algorithms:</b> Two Sum, Longest consecutive sequence, Subarray sum = K</li>
    <li><b>Patterns:</b> Frequency counting, Prefix sum + hashmap, Lookup optimization</li>
  </ul>
</li>

<li><b>4. Linked List</b>
  <ul>
    <li><b>Operations:</b> Insert (head, tail, middle), Delete, Reverse, Detect cycle</li>
    <li><b>Algorithms:</b> Floyd’s Cycle Detection, Merge lists, Find middle, Reverse in k-group</li>
    <li><b>Patterns:</b> Fast & Slow pointers, In-place reversal</li>
  </ul>
</li>

<li><b>5. Stack</b>
  <ul>
    <li><b>Operations:</b> Push, Pop, Peek</li>
    <li><b>Algorithms:</b> Next Greater Element, Valid Parentheses, Min Stack</li>
    <li><b>Patterns:</b> Monotonic Stack, LIFO</li>
  </ul>
</li>

<li><b>6. Queue</b>
  <ul>
    <li><b>Operations:</b> Enqueue, Dequeue, Circular queue</li>
    <li><b>Algorithms:</b> Sliding Window Maximum</li>
    <li><b>Patterns:</b> FIFO</li>
  </ul>
</li>

<li><b>7. Trees & Binary Trees</b>
  <ul>
    <li><b>Operations:</b> Inorder, Preorder, Postorder, Level order (BFS)</li>
    <li><b>Algorithms:</b> Height, Diameter, LCA, Balanced tree</li>
    <li><b>Patterns:</b> DFS, BFS, Divide & Conquer</li>
  </ul>
</li>

<li><b>8. Binary Search Tree (BST)</b>
  <ul>
    <li><b>Operations:</b> Insert, Delete, Search</li>
    <li><b>Algorithms:</b> Validate BST, Kth smallest, LCA (BST), Inorder (sorted)</li>
    <li><b>Patterns:</b> Ordered tree logic</li>
  </ul>
</li>

<li><b>9. Binary Search</b>
  <ul>
    <li><b>Operations:</b> Basic search, Lower bound, Upper bound</li>
    <li><b>Algorithms:</b> Rotated array search, Peak element, Binary search on answer</li>
    <li><b>Patterns:</b> Monotonic condition, Search space reduction</li>
  </ul>
</li>

<li><b>10. Graphs</b>
  <ul>
    <li><b>Operations:</b> Adjacency list, Adjacency matrix</li>
    <li><b>Algorithms:</b> BFS, DFS, Topological sort, Dijkstra, Cycle detection</li>
    <li><b>Patterns:</b> Traversal, Shortest path, Connected components</li>
  </ul>
</li>

<li><b>11. Dynamic Programming</b>
  <ul>
    <li><b>Concepts:</b> Memoization, Tabulation, State definition</li>
    <li><b>Algorithms:</b> Fibonacci, Knapsack, LCS, LIS</li>
    <li><b>Patterns:</b> 1D DP, 2D DP, Take/Not Take, Subsequences</li>
  </ul>
</li>

<li><b>12. Greedy</b>
  <ul>
    <li><b>Algorithms:</b> Activity selection, Fractional knapsack, Job sequencing</li>
    <li><b>Patterns:</b> Sort + pick best, Local → global optimal</li>
  </ul>
</li>

<li><b>13. Heaps</b>
  <ul>
    <li><b>Operations:</b> Insert, Delete, Heapify</li>
    <li><b>Algorithms:</b> Top K, Kth largest/smallest, Merge K arrays</li>
    <li><b>Patterns:</b> Min heap, Max heap, Streaming</li>
  </ul>
</li>

</ul>
